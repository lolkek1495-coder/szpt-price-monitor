Третий кейс мониторинг цен на СЦПТ(социально значимые продовольственные товары)
 Мониторинг цен на СЗПТ — прототип для хакатона

Веб-приложение: загрузка цен → приведение к цене за кг / л / шт → сравнение → сигналы для проверки.
Все данные в проекте тестовые.

## Запуск

Откройте папку проекта в VS Code, затем терминал (Terminal → New Terminal):

```
pip install -r requirements.txt
python make_test_data.py
python app.py
```

Откройте в браузере http://127.0.0.1:5000.
База `prices.db` создаётся сама. Чтобы начать с чистого листа, удалите этот файл.

## Что где лежит

| Файл | Что делает |
|---|---|
| `app.py` | вся логика: база, проверка строк, пересчёт, сигналы, страницы |
| `templates/` | HTML-страницы: сравнение, ввод, проверка, справочники |
| `make_test_data.py` | генератор тестового файла с ошибками и аномалиями |
| `test_prices.csv` | готовый тестовый файл (1256 строк) |

Главные функции в `app.py`:

- `parse_pack` — разбирает упаковку: «900 г» → 0,9 кг, «дес» → 10 шт.
- `add_price` — проверяет строку (дата, товар, точка, цена, упаковка, дубликат) и считает цену за единицу.
- `check_alerts` — создаёт сигналы. Пороги заданы в начале файла: `DEV_FROM_MEDIAN`, `RISE_LIMIT`, `ABSURD_RATIO`.

## Формат файла для загрузки

CSV, разделитель `;` или `,`, кодировка UTF-8:

```
date;outlet;product;price;pack
2026-11-09;Магазин «Береке»;Сахар;450;900 г
```

Названия товара и точки должны совпадать со справочником. Дата: `2026-11-09` или `09.11.2026`.

## Сценарий демо (2 минуты)

1. «Справочники»: показать товары и точки.
2. «Ввод цен»: загрузить `test_prices.csv`. Результат: принято 1248, отклонено 8 (с причинами), 5 сигналов.
3. Там же вручную: 450 ₸ за «900 г» → в таблице 500 ₸/кг (пример из задания).
4. «Сравнение»: товар «Сахар», район «Центр» — на графике виден скачок максимума.
5. «Проверка»: сахар +41 % к медиане района, гречка в Тасбогете +14 %, хлеб с ошибкой упаковки. Записать вывод, сменить статус.
